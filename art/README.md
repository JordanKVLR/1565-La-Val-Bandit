# Drop-in art

Put generated images here and list them in `manifest.json`. Paths are relative to this folder.
Anything not listed keeps its placeholder. See `docs/ART_PROMPTS.md` for the prompts and sizes.

```json
{
  "portraits": { "ninu": "portraits/ninu.png" },
  "terrain": { "plain": "terrain/plain.png" },
  "terrainSides": { "plain": "terrain/side-soil.png" }
}
```
